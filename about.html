About TaskFlow

A lightweight, containerized task-management application deployed automatically via a full CI/CD pipeline using GitHub Actions, Docker Hub, and Render.

What is TaskFlow?

TaskFlow is a simple task management web application that helps individuals and teams create, track, and complete tasks. It provides clear visibility into pending and completed work through an intuitive interface built with pure HTML and CSS.

Built for DevOps

TaskFlow demonstrates a complete CI/CD pipeline in action. Every code change goes through automated build, containerization with Docker, and live deployment to Render — triggered automatically by GitHub Actions with zero manual steps required.

Team Collaboration

Built collaboratively by five members, each owning one page. Feature branches and Pull Requests ensured every contribution was reviewed and passed automated CI checks before being merged into the main develop branch.

How to Use TaskFlow

1

Dashboard — Get an Overview

Start at the Dashboard to see a summary of all your tasks: total count, tasks in progress, and completed tasks. Use the New Task button to quickly jump to the task creation form.

2

Add Task — Create a New Task

Go to New Task in the navigation bar. Fill in the task title, a short description, the due date, and assign a priority level (High, Medium, or Low). Submit the form to add the task to your board.

3

Task List — Browse and Filter Tasks

Navigate to Tasks to see all tasks in a table view. Use the filter buttons — All, Pending, or Completed — to narrow down what you are looking at and focus on what matters.

4

Task Detail — View, Complete, or Delete

Open Task Detail to view the full information of a selected task. From here you can mark the task as complete to move it out of your pending list, or delete it if it is no longer needed.

5

Navigation — Move Between Pages

Use the top navigation bar available on every page to jump between Dashboard, Tasks, New Task, Task Detail, and About at any time. The currently active page is highlighted in the navigation bar for easy orientation.
